SSavoir BÊTA __VERSION__

Installé. Encore trois petits pas.

Pas de modèle à télécharger, pas de console à lancer.
Le navigateur démarre le connecteur lorsque vous ouvrez Savoir.

  1. Ouvrez la page des extensions

    Saisissez chrome://extensions dans Chrome, ou edge://extensions dans Edge. Activez le mode développeur.

    La version bêta n’est pas encore disponible dans le Chrome Web Store.

  2. Chargez le dossier Savoir

    Cliquez sur Charger l’extension non empaquetée, puis sélectionnez le dossier ci-dessous.

    Désactivez une ancienne version de cette extension si elle est encore présente. Identifiant attendu : __EXTENSION_ID__.

  3. Ouvrez une vidéo, puis Savoir

    Sur YouTube, cliquez sur Savoir sous la vidéo, puis sur Continuer avec ChatGPT. Connectez-vous uniquement sur la page officielle OpenAI.

    L’accès dépend des autorisations et quotas de votre compte. La connexion et la génération réelles restent à vérifier avec votre compte ; aucun achat ni accès API payant de secours n’est activé.

Résumer ou envoyer une question transmet le texte nécessaire à OpenAI. Les réponses IA peuvent être erronées ; vérifiez les passages cités. Sans sous-titres accessibles, vous pouvez coller une transcription. Aucun audio ni modèle ne sera téléchargé.

Installateur non signé. Les données locales sont conservées à la désinstallation. Un ancien autostart de l’extension est sauvegardé avant retrait ; aucun autre service n’est arrêté.
